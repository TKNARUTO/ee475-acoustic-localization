# Phone playback input

The current signal is [HF2 gap, 18–22 kHz](HF2-gap-test/README_EN.md). Use its WAV for controlled tests or the matching MP3. The independent Pico reference is fixed; this folder does not offer switchable frequency modes. Old 19–21 kHz/TONE preset instructions no longer apply to the active workflow. Phone platform: Beacon Loop 1.2, Android API 26+ / target 35; leave optional Normalize off initially.
