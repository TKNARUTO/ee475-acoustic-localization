# 当前固定 HF2 gap 手机信号

使用 `01_LOCATE_18-22kHz_43ms-gap.wav` 或对应 MP3。Beacon Loop 1.2 内置 WAV 与这里的 WAV 逐字相同。这是当前独立 Pico 的正式测试信号，不是旧 19–21 kHz 预设的可选替代品。

| 参数 | 数值 |
|---|---|
| 标称频带 | 18,000–22,000 Hz；标称中心 20,000 Hz |
| 采样率／PCM | 48,000 Hz／有符号 16 位 WAV |
| 容器／信号声道 | 双声道；左通道为零，右通道承载信号 |
| 周期 | 4096 点 = 85.333 ms |
| 发声／静音 | 2048＋2048 点 = 42.667＋42.667 ms |
| WAV 总长 | 589,824 帧 = 12.288 s = 144 周期 |
| 实测右通道 PCM 上下界 | -11468 至 10923 |
| WAV SHA-256 | `e182fddee2615ed15b826e9d781c041ae557e59fcb6aa2ed7feb6274e3e9b9a1` |
| MP3 SHA-256 | `0aa6cec03b66ef44d4708ea3cbc2adefab025f5b5b3c481bb2f71f8ed4cd69bb` |

静音与原始首尾渐变属于编码，不要剪掉或拉伸。可重复波形比较优先 WAV；MP3 编码／解码填充和手机处理会影响实际循环边界，软件循环不能直接证明声学无缝。

独立 Pico 固定使用此参考并自动扫描，Windows 只是方向／时序监视器。更换手机文件不会改变 Pico 模板。归档的 PC＋Pico 组合另有兼容参考导入流程，并加载旧采集固件，不要把其启动器与独立监视器混用。

平台：Beacon Loop 1.2 要求 Android 8.0/API 26 或以上，目标 API 35。初测关闭 Normalize，固定位置和朝向，记录媒体音量。若启用，增益最多 +3 dB，目标峰值上限 −3 dBFS；它不改变接收参考，也不保证距离。18 kHz 附近可能听得见，扬声器频带、几何、反射和听力各不相同，因此不承诺固定范围或完全不可听。电脑不要播放信标。
