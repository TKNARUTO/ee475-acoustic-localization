# Beacon Loop 1.2 版本记录

## 2026 年 11 月 12 日 — 仅整理文书

中英文说明分开，明确手机一般文件导入与当前独立 Pico 固定 HF2 参考的区别。源码、APK、音频、构建脚本和本地配置均未修改，移除了指向已迁出 Android 归档的旧链接。

## 2026 年 11 月 5 日 — 保留的 1.2 发布

1.2／版本号 3 将 HF2 gap 设为唯一内置及默认音频，保留本地导入、PCM 循环和可选增益，移除旧内置信号选择器。旧内置信号缓存选择迁移到 HF2 gap，自选缓存保留；缓存缺失时回退到名称正确的默认音。间歇、首尾渐变、频率、采样率和声道结构均保留。

记录构建环境为 Windows、JDK 25.0.4.1+1、Android API 35、Android 15 build-tools，Java 源码／目标设置为 8。运行最低 API 26，目标 API 35。APK 构建、v2/v3 签名、ZIP 对齐、包元数据、WAV 匹配和九项 PcmGain 检查离线通过；与 PC 参考波形的相关系数为 0.9999999959766115。这些是历史离线检查，不是手机完整验收。
