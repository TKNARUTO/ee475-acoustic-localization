# Original reference materials

These files are retained source references, not the active operating manual. Original project notes/proposal, hardware datasheets, schematic and supplied photographs are preserved byte-for-byte. External documents retain their original language and authorship; this revision does not translate or rewrite them.

Vendor documents may concern related board revisions. A photograph's left/right view is not a substitute for GPIO labels and physical pin numbers. Use [current Pico instructions](../pico-standalone/README_EN.md) and the current project handoff for the actual firmware, wiring, age/validity limits and platform requirements. The old PC+Pico combo has its own archived manual. Historical material does not prove compatibility or current test acceptance.
