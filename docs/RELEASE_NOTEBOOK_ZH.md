# 发布整理阶段笔记
## 需求与边界
把麦克风 → Pico → ESP32 阶段完整交接给队友和队友 AI：软件英文，说明文书中英文分文件，写清平台细节，整理本地并同步 GitHub。legacy 只保留最终电脑＋Pico 模板。本阶段不继续 FFT 优化，也不修改电机行为。

## 决定与依据
Pico SDK 与 Arduino 分目录，因为工具链、构建选项和职责不同。保存源码与烧录镜像哈希，避免把编译成功当成烧录成功。无效但有限的拟合继续用于诊断，有效位／过期逻辑不变。通信字段相等与未知的真实角度误差分开陈述。历史文件带哈希移到活跃项目外，保证工程资料可恢复。

本地工程继承了父级 EE475 的 Git 仓库，所以使用独立 checkout 发布。通过可分享文件清单排除日志、原固件备份和签名资料。严格先更新本地，发布后逐文件核对。用 PowerShell／Git，不操作网页。

## 已做改动
本阶段保留当前固件、声学源码和手机参考音。电脑安装脚本不再引用已移走的根目录组合文件夹。主要入口是 Start.cmd 与 Update.cmd。README 区分 Arduino 板卡包、NodeMCU 板型和 COM 端口，也写明 Pico SDK、编译器和烧录方式。组件角色、GPIO、带宽、伪代码、预计问题、测试证据和限制均有独立中英文说明。最终组合模板源码／二进制不变，只更新文书与 ZIP。

## 验收
