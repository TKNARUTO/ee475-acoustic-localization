# Current operation

Run Update-and-Start.cmd. It validates and refreshes local RX4 code, gracefully restarts a compatible app and confirms its version. Select Start Scan; loop the matching LOCATE file on the phone. The app has no computer speaker playback. Import Beacon accepts compatible periodic files; the phone must play the same source. Set Front changes only the view reference after stable bearings. Advanced holds diagnostic channels, history and manually labelled trials.

Use a fixed phone position/volume for accuracy tests and a separate movement trial for tracking. Record manual pause times. Large raw changes without true-bearing data are observations, not proof of a wrong direction. Automatic short captures are bounded at four per app session. Full phone trials use tests/capture_rx4_phone_trial.py --gui --seconds 90 and remain finite.

Read the illustrated report and time-series CSV before adjusting thresholds. Old launchers and recordings are under legacy; see LEGACY_MIGRATION.csv for their former locations.
