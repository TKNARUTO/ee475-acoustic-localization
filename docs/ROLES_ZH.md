# 角色与工作范围

本项目当前负责 SEN0325＋Pico 采集、电脑端信标检测与方向显示、验证报告，以及手机本地循环播放器。手机负责发声；阵列负责接收；Pico负责同步数字采集；电脑负责估计方向。界面圆环不表示真实距离。

用户负责接线、电源检查、手机音量与朝向、人工中断说明、真实方位/距离测量。Agent负责代码、有限时长测试、证据保存、分析与文档；行为改动应先说明。不能仅因角度变化大而拒绝方向。

ESP32、车头距离传感器、底盘电机和避障属于后续集成范围，当前没有电机控制输出。未确认的队员姓名与分工不自行编造。

活动源码、测试、音频、阶段、报告和参考资料按README分类。legacy是历史材料，可供查证和读取固定测试样本，不是当前运行入口。旧路径可通过LEGACY_MIGRATION.csv查找。
