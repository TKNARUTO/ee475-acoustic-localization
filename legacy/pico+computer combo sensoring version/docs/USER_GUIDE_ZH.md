# 接收软件使用

1. 运行模板的 `一键启动.cmd`，打开电脑运算接收器，默认使用 coded-gap。
2. Pico 接好后点 Start Scan；必要时进入 BOOTSEL，加载随包 v0.6 RAM 采集固件。
3. 手机循环播放随包 HF2 gap WAV/MP3 或 Beacon Loop 1.2 内置信标。初测可固定在约 0.5 m，记录位置和媒体音量。
4. 同时看方向、有效性、波形和频谱。箭头可能停留约 1.5 s，不代表新测量；圆圈不表示距离。
5. Set Front 只设置显示参考，真实大角度运动仍允许。精度要用已知角度实测。
6. 自定义定位音必须是兼容的周期信号，手机音频与电脑参考要匹配；自选导入不会随归档分享。
7. 另一程序使用 Pico 前先 Stop Scan 或关闭本接收器。Update.cmd 会请求正常重启并等录制关闭。

电脑不播放信标。用户主动暂停手机和没有记录的移动，不应直接归因于通信故障。本包不包含电机或距离传感器控制。

平台与工具：电脑端使用 Windows 10/11、Python 3.12+（含 Tcl/Tk）；Pico 通过 USB 采集。手机播放器需 Android 8.0/API 26 或以上。运行旧固件不需要编译器；工具版本及限制见[平台说明](../PLATFORM_ZH.md)。当前独立 Pico 程序位于模板根目录上两级的 `pico-standalone/`，不包含在本 ZIP 内。
