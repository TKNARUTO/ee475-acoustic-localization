# 保留组合的智能体说明

先阅读 README_ZH.md、FILE_CATALOG_ZH.md 和 PLATFORM_ZH.md。本模板是手机→SEN0325→Pico USB 采集→Windows 方向计算，不是独立 Pico 部署。

- 保留源码、配置、启动器、音频、APK、UF2 和 ELF；实验应在另一个副本进行。
- 保留 v0.6-RX2 RAM 二进制；相邻 v0.8-BRIDGE 源码不是已确认的匹配重建来源。RAM 断电需重载。
- 基线比较时 bridge_config.json 保持关闭。电机和 ESP32 固件不在此模板范围。
- 不因角度变化大而拒绝方向；区分停留箭头、新观测、时延和实物精度。
- 手机播放，电脑只接收；保持两端信标、采样率和通道映射一致。
- 原始录音、凭据、自选音频和工具链留在本地；验证结果写到冻结模板外。
- 离线测试不需要硬件；硬件任务需明确范围并独占设备。
- 新实验应更新说明和来源记录，不得悄悄覆盖此基线。

平台与工具：电脑端使用 Windows 10/11、Python 3.12+（含 Tcl/Tk）；Pico 通过 USB 采集。手机播放器需 Android 8.0/API 26 或以上。运行旧固件不需要编译器；工具版本及限制见[平台说明](PLATFORM_ZH.md)。当前独立 Pico 程序位于模板根目录上两级的 `pico-standalone/`，不包含在本 ZIP 内。
