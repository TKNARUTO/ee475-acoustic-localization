# Phone quick start

Install the included 1.2 APK, choose the default HF2 gap beacon, leave Normalize off, set media volume and press Play loop. Start Scan separately on the Windows receiver. Pause controls phone playback. Importing another file requires a matching compatible receiver reference. See [full player instructions](README_EN.md) for signature/upgrade and gain limitations.

Platform/tools: Windows 10/11, Python 3.12+ with Tcl/Tk and Pico USB capture; phone player: Android 8.0/API 26+. A compiler is not needed to run the retained binary. See [platform requirements](../PLATFORM_EN.md) for versions and limits. In the full repository, the current independent Pico program is at `../../pico-standalone/` relative to the template root; this ZIP does not include it.
