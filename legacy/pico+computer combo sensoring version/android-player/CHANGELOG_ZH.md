# 保留的 Android 1.2 发布记录

2026 年 11 月 5 日发布的 1.2（版本号 3）只内置并默认使用 HF2 gap，保留本地导入、PCM 循环和可选受限增益。旧内置信号选择器已移除，旧内置缓存名迁移到 gap；自选文件缓存保留，缓存缺失时回退到名称正确的 gap。

原发布记录包含 APK 构建成功、签名／对齐／元数据检查、仅 gap 的资源清单、源码／APK／手机波形一致、参考相关系数 0.999999996，以及九项增益测试。这些是历史构建记录，不能当成本次文书更新新完成的测试。打包没有确认手机安装、熄屏、媒体抢占或实际定位表现。

证书 SHA-256：`32d13ff773b36c8438220db4fb63b6daf5e6da6d829b6ef11f7febe2571ce037`。它与原 1.0 一致，与导入的另一签名 1.1 不一致。密钥不分享。更早 APK、旧内置音频及构建输出在此最终精简模板之外，其历史本地路径不是本包运行依赖。频率、采样率、编码、通道、间歇与首尾渐变都未修改。

平台与工具：电脑端使用 Windows 10/11、Python 3.12+（含 Tcl/Tk）；Pico 通过 USB 采集。手机播放器需 Android 8.0/API 26 或以上。运行旧固件不需要编译器；工具版本及限制见[平台说明](../PLATFORM_ZH.md)。当前独立 Pico 程序位于模板根目录上两级的 `pico-standalone/`，不包含在本 ZIP 内。
