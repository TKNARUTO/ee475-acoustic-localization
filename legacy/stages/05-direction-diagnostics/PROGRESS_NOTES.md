# RX3 阶段笔记

本阶段先解决重复确认造成的等待，再补原始录音诊断，没有一次改动多个定位阈值。

1. 旧日志中 126 个等待确认窗口，有 121 个此前已经连续识别到代码。确认流程与方向拟合耦合，是可以明确修复的一处问题。
2. 修改后，通过原有几何拟合的方向可以及时显示；大角度变化不再重启确认。未通过的方向仍然拒绝。
3. 两段实际原始音频同输入回放，输出次数由 1→5、0→2，确认修改有实际作用；它们是失败触发的问题片段，不能代表整体成功率。
4. 剩余问题缩小到配对时差估计：25 个可分析失败窗口中 20 个连任意到达时间都不能很好解释。不能仅靠调最终几何阈值解决。
5. 当前帧代替历史平均的离线实验帮助很小，未部署。下一阶段再做共同到达时间和选峰改进。

用户现场反馈：延迟改善明显，仍有间歇方向丢失。当前版本保持运行供测试。完整说明见 [阶段报告](../../reports/direction-continuity-2026-10-27/DIRECTION_CONTINUITY_ZH.md)，操作和文件位置见 [README](README.md)。
